# Drop real assets here

Add these exact filenames to this folder (drag-and-drop on GitHub.com works fine — use "Add file → Upload files" on this folder, or replace this file directly). Each one is picked up automatically on the next build, no code changes needed.

| Filename | Used on |
|---|---|
| `s2-logo.png` | Header + footer, every page |
| `home-hero.png` | Home page hero banner |
| `service-header.png` | Service page hero banner |
| `s2-qr.png` | Home page "Visit Us" contact card |

Until a file is present, its spot on the site shows an on-brand placeholder (gold monogram for the logo, a CSS-recreated hero, a striped box for the QR).
